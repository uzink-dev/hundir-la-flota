# Hundir la flota

Juego de Hundir la flota desarrollado en Python, en el que
un jugador compite contra la máquina.

## Requisitos

- Python 3
- NumPy

## Instalación

Instalar las dependencias:

```bash
pip install -r requirements.txt
```

## Ejecución

Desde la carpeta del proyecto:

```bash
python3 main.py
```

## Reglas

- Cada jugador tiene un tablero de 10 x 10.
- Cada tablero contiene 10 barcos que ocupan 20 casillas.
- El jugador comienza la partida.
- Las coordenadas se introducen como fila,columna.
- Si un disparo acierta, el jugador repite turno.
- Si falla, el turno pasa al contrario.
- No se permiten disparos repetidos.
- Gana quien alcanza todas las casillas de los barcos enemigos.

## Archivos del proyecto

- variables.py: configuración y constantes.
- clases.py: clase Tablero.
- funciones.py: funciones auxiliares.
- main.py: ejecución del juego.
